# アプリ仕様書: TimeIsMoney (MVP版)

## 1. アプリ概要
- **アプリ名**: TimeIsMoney
- **プラットフォーム**: Flutter Web（Google Chrome対応、スマホ幅450pxのレスポンシブ中央配置）
- **ターゲット**: ショート動画やSNSの無意識スクロールで時間を浪費している若者層
- **コアコンセプト**:
  - **GDT（Gross Domestic Time：国内総時間）**: 時間を24時間の限られた資産と定義。浪費時間を時給換算して金銭的損失（赤字）として可視化する。
  - **目標連動ポイント制（ゲーミフィケーション）**: オンボーディングで設定した個人の目標に直結する行動を高倍率（ポイント3倍）で評価し、浪費行動を減点・損失として扱う。
- **データ管理**: 端末内ローカル保存（`shared_preferences`、ログイン認証なし）

## 3. データモデル & 状態管理仕様

### ユーザー設定（UserSettings）
- `hourlyRate` (double): ユーザーの時給換算値（初期値: 1,000）
- `currencySymbol` (String): 通貨記号（初期値: "¥"、"$"と切替可能）
- `focusGoal` (String): オンボーディングで設定した注力目標（初期値: "TOEIC / 英語学習"）
- `isFirstLaunch` (bool): 初回起動フラグ（初期値: true。オンボーディング完了で false に更新）

### 日次記録（TimeRecord）
- `essentialHours` (double): 必須時間（睡眠・食事など、デフォルト 10.0h）
- `investmentHours` (double): 投資時間（目標勉強・運動など、デフォルト 6.0h）
- `wasteHours` (double): 浪費時間（SNS・ショート動画など、デフォルト 8.0h）
- ※ 合計24時間を基準として管理。

---

## 4. 計算ロジック

### ① GDT損害額（金銭的損失）
- **本日の損害額**: `todayLoss = wasteHours * hourlyRate`
- **年間換算損害額**: `annualLoss = todayLoss * 365`

### ② デイリーフォーカスポイント
- **投資時間（目標タスク）**: `1時間あたり +60pt × 3倍ボーナス = +180pt/h`
- **必須時間（生活維持）**: `1時間あたり +30pt/h`
- **浪費時間（ブラックホール行動）**: `1時間あたり -50pt/h（減点）`
- **本日合計スコア**: 各カテゴリのポイント合計値（最低値 0pt）

### ③ デイリー決算判定
- **時間黒字（TIME SURPLUS）**: `investmentHours >= wasteHours`
- **時間破産（TIME BANKRUPT）**: `investmentHours < wasteHours`

## 5. 画面構成 & 機能要件

### 画面1: オンボーディング画面（OnboardingScreen）
- **表示条件**: `isFirstLaunch == true` の初回起動時のみ表示。
- **スライド構成（3ステップスワイプ）**:
  - **Slide 1 [概念]**: タイトル「What is your GDT?」 / 本文「GDPがお金の指標なら、GDT（国内総時間）は人生の指標。あなたの1日は24時間という限定された資本です。」
  - **Slide 2 [課題]**: タイトル「Stop Invisible Losses」 / 本文「SNSやショート動画の無意識スクロールで、年間数十万円分の時間をドブに捨てていませんか？」
  - **Slide 3 [目標設定]**: タイトル「Set Your Focus Goal」 / 本文「時間を投資したい目標を1つ選んでください。この行動はポイントが3倍になります！」
    - 選択肢チップ: `TOEIC / 英語学習`, `資格取得 / プログラミング`, `ボディメイク / 筋トレ`, `読書 / 副業`
- **CTAボタン**: 「GDTを計測し始める」（タップで目標を保存し、`isFirstLaunch = false` にしてダッシュボードへ遷移）

### 画面2: メインダッシュボード（DashboardScreen）
- **ボトムナビゲーション**: Dashboard / Routine / Settings の3タブ構成。
- **ヘッダー**:
  - アプリ名「TimeIsMoney」
  - 浪費警告バナー: `⚠️ 浪費警戒レベル：自分の時間を取り戻せ`
- **TODAY'S LOSS カード**:
  - 浪費損害額を巨大な赤太字で表示（例: `-¥8,000`）。
  - サブ情報: `浪費 [wasteHours]h × [currencySymbol][hourlyRate]/h` / `年間ペース: -[annualLoss]`
- **FOCUS SCORE カード**:
  - 獲得ポイントをゴールド太字で表示（例: `+1,080 Pt`）。
  - ラベル: `目標「[focusGoal]」の取り組みでポイント3倍適用中！`
- **24時間内訳バー**:
  - 3色（青: 必須 / 緑: 投資 / 赤: 浪費）のプログレスバーで24時間の割合を表示。
  - 各項目の時間数（h）と割合（%）を凡例表示。
- **クイックアクションボタン**:
  - 「⚡ 習慣テンプレートを適用する」（タップでRoutineScreenへ遷移）。

### 画面3: 習慣入力画面（RoutineScreen）
- **目的**: 毎日の入力コストをゼロに近づけるプリセット選択とスライダー微調整。
- **プリセットカード**:
  - `平日集中パターン`: 必須 8h / 投資 7h / 浪費 1h
  - `ダラダラ休日パターン`: 必須 9h / 投資 1h / 浪費 8h（赤枠警告付き）
  - `バイト・両立パターン`: 必須 8h / 投資 4h / 浪費 3h
  - カード選択で各カテゴリの時間値が一括反映される。
- **スライダー調整**:
  - 浪費時間をスライダー（0h〜16h、0.5h刻み）で動かすと、画面上の「予想損害額」がリアルタイムに増減。
- **確定ボタン**: 「このパターンを記録する」（タップで状態を更新しダッシュボードへ戻る）。

### 画面4: 設定画面（SettingsScreen）
- **時給設定セクション**:
  - 時給入力フィールド（数値入力）。
  - クイック選択チップ: `¥1,000`, `¥1,500`, `¥2,500`, `¥5,000`。
- **通貨設定**: `JPY (¥)` と `USD ($)` の切り替え。
- **デイリー決算ボタン**:
  - 「📊 今日のGDTを決算する」ボタンをタップするとモーダルダイアログを表示。
  - 黒字時: 「🎉 TIME SURPLUS！本日は目標への投資が浪費を上回りました！」
  - 赤字時: 「💀 TIME BANKRUPT... 本日は [todayLoss] 分の未来を無駄にしました。」
